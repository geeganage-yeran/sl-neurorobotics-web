# 🧠 SL Neurorobotics

A **web-based platform for customizing and selling EEG devices and neuro-assistive technologies** in Sri Lanka 🇱🇰.  
This project aims to enhance the **accessibility, affordability, and personalization** of neurotechnology through a modern, AI-driven e-commerce solution.

---

## 🚀 Features

- 🤖 **AI-Powered Recommendations** – Personalized product suggestions and Q&A using OpenAI API.  
- 🕶️ **Augmented Reality (AR) Product View** – WebXR-based 3D model visualization in real environments.  
- 🔒 **Secure Authentication** – JWT-based user registration and login.  
- 💳 **E-Commerce Platform** – Product catalog, Stripe payment integration, and real-time order tracking.  
- ⚙️ **Full-Stack Architecture** – Seamlessly integrates AI, AR, and e-commerce functionalities.  

---

## 🧠 Tech Stack Overview

- **Front-End:** React + Vite  
- **Back-End:** Spring Boot (Java)  
- **AI/ML:** Python (Flask) with Tripo SR (2D → 3D) & OpenAI API  
- **Database:** MySQL  
- **AR:** WebXR  
- **Cloud:** Google Cloud Platform (GCP)  
- **Payments:** Stripe Integration  
- **Methodology:** Agile (Scrum)
